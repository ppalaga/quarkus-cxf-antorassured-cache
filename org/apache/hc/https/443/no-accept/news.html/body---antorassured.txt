<h1>HttpComponents Project News</h1><section><section><section><section><section><a id="a23_Nov_2026_-_HttpComponents_Core_5.5_GA_released"></a>
<h6>23 Nov 2026 - HttpComponents Core 5.5 GA released</h6>
<p>This is the first GA release in the 5.4 release series. This release improves HTTP/2 protocol conformance and prevention of commom HTTP/2 denial-of-service attacks, improves connection and session pool implementations, adds support for Structured Field Values and QUERY method.</p>
<p>Notable changes and features included in the 5.5 series:</p>
<ul>

<li>
<p>Improved connection pool implementation.</p></li>
<li>
<p>Added HTTP message stream APIs and support for HTTP/2 message stream timeouts.</p></li>
<li>
<p>Updated SSLContexts to respect system properties by default.</p></li>
<li>
<p>Limited pending HTTP/2 request commands per connection.</p></li>
<li>
<p>Improved conformance with RFC 7540, HPACK (RFC 7541), and HTTP/2 (RFC 9113).</p></li>
<li>
<p>Building HttpCore with Maven now requires Java 17 or newer. Published artifacts remain compatible with Java 8.</p></li>
<li>
<p>Added support for the QUERY method (RFC 10008).</p></li>
<li>
<p>Added support for Structured Field Values for HTTP (RFC 9651).</p></li>
<li>
<p>Added support for Digest Fields (RFC 9530).</p></li>
<li>
<p>Improved async IOSession pool implementation.</p></li>
<li>
<p>HTTP/2 control frame excessive use and rapid stream reset protection.</p></li>
</ul></section><section><a id="a26_Oct_2026_-_HttpComponents_Client_5.7-beta1_released"></a>
<h6>26 Oct 2026 - HttpComponents Client 5.7-beta1 released</h6>
<p>This is the first BETA release in the 5.7 release series. In this release, idle connection eviction is deprecated in favor of connection expiration management and expired connection eviction. This release also introduces configuration improvements to HTTP/2 session pooling (HTTP/2 connection pool with message multiplexing) and SSE support improvements as well as HTTP header parsing optimization.</p>
<p>Notable changes and features included in the 5.7 series:</p>
<ul>

<li>
<p>[Experimental] Server-Sent Events (SSE) client optimized to handle push event streams.</p></li>
<li>
<p>[Experimental] WebSocket protocol support (client-side and server-side).</p></li>
<li>
<p>[Experimental] Optional execution queue that enforces a limit on the number of requests executed concurrently by the same async client instance.</p></li>
<li>
<p>Caffeine-based cache backend.</p></li>
<li>
<p>OFFLOCK pool concurrency policy for connection pools (classic and async).</p></li>
<li>
<p>TLS-Required mode support.</p></li>
<li>
<p>Jakarta REST client, supporting a subset of jakarta.ws.rs APIs.</p></li>
<li>
<p>QUERY method support / QUERY response caching support.</p></li>
</ul></section><section><a id="a14_Oct_2026_-_HttpComponents_Core_5.5-beta4_released"></a>
<h6>14 Oct 2026 - HttpComponents Core 5.5-beta4 released</h6>
<p>This BETA release features multiple HTTP/2 protocol conformance improvements and perfroance optimizations, introduces support for Digest Fields (RFC 9530), and improves async IOsession pool functionality.</p></section><section><a id="a12_Oct_2026_-_HttpComponents_Client_5.6.5_GA_released"></a>
<h6>12 Oct 2026 - HttpComponents Client 5.6.5 GA released</h6>
<p>This maintenance release fixes several defects found since the previous release including the defect in the async Brotli decompression code that can cause the message exchange to hang indefinitely. It also upgrades HttpCore to version 5.4.4.</p></section><section><a id="a24_Sept_2026_-_HttpComponents_Core_5.5-beta3_released"></a>
<h6>24 Sept 2026 - HttpComponents Core 5.5-beta3 released</h6>
<p>This BETA release migrates JSON bindings to Jackson 3, introduces support for Structured Field Values (RFC 9651), and improves and optimizes message parsing support methods. It is expected to be the last BETA release before 5.5 GA.</p></section><section><a id="a24_Sept_2026_-_HttpComponents_Core_5.4.4_GA_released"></a>
<h6>24 Sept 2026 - HttpComponents Core 5.4.4 GA released</h6>
<p>This maintenance release optimizes HTTP/1.1 message buffer configuration and corrects the handling of asynchronous entity producer state resets after interrupted writes.</p></section><section><a id="a17_Aug_2026_-_HttpComponents_Client_5.7-alpha1_released"></a>
<h6>17 Aug 2026 - HttpComponents Client 5.7-alpha1 released</h6>
<p>This is the first ALPHA release in the 5.7 release series. It introduces several new modules with Server-Sent Events (SSE) client, WebSocket client and Jakarta REST client implementations that build upon the common foundation of the core and client modules. Please note the Jakarta REST client presently supports a sub-set of jakarta.ws.rs APIs only. This release series also introduces full support for QUERY method including QUERY response caching.</p></section><section><a id="a10_Aug_2026_-_HttpComponents_Client_5.6.4_GA_released"></a>
<h6>10 Aug 2026 - HttpComponents Client 5.6.4 GA released</h6>
<p>This maintenance release fixes SSL parameter application in the async TLS upgrade strategy.</p></section><section><a id="a31_July_2026_-_HttpComponents_Client_5.6.3_GA_released"></a>
<h6>31 July 2026 - HttpComponents Client 5.6.3 GA released</h6>
<p>This maintenance release fixes a resource management defect in the content decompression protocol handler of the classic transport.</p></section><section><a id="a30_June_2026_-_HttpComponents_Client_5.6.2_GA_released"></a>
<h6>30 June 2026 - HttpComponents Client 5.6.2 GA released</h6>
<p>This maintenance release upgrades HttpCore to the latest stable version and restores lazy content decompression by the classic client transport.</p></section><section><a id="a25_June_2026_-_HttpComponents_Core_5.5-beta2_released"></a>
<h6>25 June 2026 - HttpComponents Core 5.5-beta2 released</h6>
<p>This BETA release corrects Java 8 binary problem introduced in the previous BETA release. The previous version has been compiled against Java 17 APIs by mistake. This release also adds support for QUERY method (RFC 10008).</p></section><section><a id="a25_June_2026_-_HttpComponents_Core_5.4.3_released"></a>
<h6>25 June 2026 - HttpComponents Core 5.4.3 released</h6>
<p>This maintenance release fixes several defects and regression reported since the previous release including a regression in backpressure handling of async TLS sessions introduced in version 5.3.3.</p></section><section><a id="a5_June_2026_-_HttpComponents_Core_5.5-beta1_released"></a>
<h6>5 June 2026 - HttpComponents Core 5.5-beta1 released</h6>
<p>This is the first BETA release in the 5.5 release series that improves performance and robustness of connection pool implementations, further improves HTTP/2 specification conformance and introduces JSON message content bindings based on <a href="https://github.com/fasterxml/jackson" class="externalLink">Jackson</a> version 2.</p></section><section><a id="a20_April_2026_-_HttpComponents_Client_5.6.1_GA_released"></a>
<h6>20 April 2026 - HttpComponents Client 5.6.1 GA released</h6>
<p>This is a maintenance release that disables the experimental SCRAM auth scheme by default and fixes SCRAM final response handling. The SCRAM auth scheme can be re-enabled by choosing a custom auth scheme preference sequence that explicitly includes SCRAM auth.</p></section><section><a id="a26_March_2026_-_HttpComponents_Core_5.5-alpha1_released"></a>
<h6>26 March 2026 - HttpComponents Core 5.5-alpha1 released</h6>
<p>This is the first ALPHA release in the 5.5 release series that improves performance and robustness of connection pool implementations, further improves HTTP/2 specification conformance and introduces JSON message content bindings based on <a href="https://github.com/fasterxml/jackson" class="externalLink">Jackson</a> version 2.</p></section><section><a id="a6_March_2026_-_HttpComponents_Core_5.4.2_GA_released"></a>
<h6>6 March 2026 - HttpComponents Core 5.4.2 GA released</h6>
<p>This maintenance release fixes a bug in the lax connection pool where expired connection cleanup fails to update the number of available connections, potentially causing the client to eventually deadlock. Two other fixes are included as well, one for a memory leak in the implementation of HTTP/2 stream priority and one in the parseLenient method, which should ignore illegal character names.</p></section><section><a id="a11_February_2026_-_HttpComponents_Core_5.4.1_GA_released"></a>
<h6>11 February 2026 - HttpComponents Core 5.4.1 GA released</h6>
<p>This maintenance release fixes a latency regression in the async transport caused by TCP_NODELAY failing to be set. Several other bugs have also been fixed affecting connection management, HTTP/2 exception handling and propagation</p></section><section><a id="a22_December_2025_-_HttpComponents_Client_5.6_GA_released"></a>
<h6>22 December 2025 - HttpComponents Client 5.6 GA released</h6>
<p>This is the first GA release in the 5.6 release series. It adds several features such as transport content decompression and content compression for the async transport, support for Unix sockets, experimental support for SCRAM-SHA-256 authentication scheme, and Micrometer/OTel observations &amp; metrics.</p>
<p>Notable changes and features included in the 5.6 series:</p>
<ul>

<li>
<p>Unix domain socket support.</p></li>
<li>
<p>Support for pluggable content codecs via Commons-Compress in the classic transport. (optional).</p></li>
<li>
<p>Support for transparent content decompression and content compression with <code>deflate</code>, <code>gzip</code>, <code>zstd</code> (optional), and <code>brotli</code> (optional) codecs in the async transport.</p></li>
<li>
<p>Micrometer/OTel observations &amp; metrics (optinal).</p></li>
<li>
<p>Off-lock connection disposal by the classic pooling connection manager. Experimental.</p></li>
<li>
<p>SCRAM-SHA-256 authentication scheme (RFC 7804). Experimental.</p></li>
<li>
<p>Request Priority support (RFC 9218). Experimental.</p></li>
<li>
<p>OFFLOCK connection pool concurrency policy. Experimental.</p></li>
</ul></section><section><a id="a22_December_2025_-_HttpComponents_Client_5.5.2_GA_released"></a>
<h6>22 December 2025 - HttpComponents Client 5.5.2 GA released</h6>
<p>This is a maintenance release that fixes incompatibility with the 5.4 branch of HttpCore.</p></section><section><a id="a16_December_2025_-_HttpComponents_Core_5.4_GA_released"></a>
<h6>16 December 2025 - HttpComponents Core 5.4 GA released</h6>
<p>This is the first GA release in the 5.4 release series that improves HTTP/2 protocol support by ensuring conformance to the latest HTTP specification (RFC 9113) and adds support for Unix domain sockets.</p>
<p>Notable changes and features included in the 5.4 series:</p>
<ul>

<li>
<p>Experimental OFFLOCK (lock-free) connection pool.</p></li>
<li>
<p>Conformance to RFC 9218 (Extensible Prioritization Scheme for HTTP).</p></li>
<li>
<p>Improved conformance to RFC 9113 (Hypertext Transfer Protocol Version 2).</p></li>
<li>
<p>Five-second TCP keep-alive enabled by default.</p></li>
<li>
<p>Unix domain socket support by the classic and async transports.</p></li>
<li>
<p>Redesign of classic over async API bridge.</p></li>
<li>
<p>Improved URI encoding per RFC 3986.</p></li>
<li>
<p>QUERY method support.</p></li>
<li>
<p>Improved idle connection validation in the async transport.</p></li>
</ul></section><section><a id="a27_October_2025_-_HttpComponents_Client_5.6-alpha1_released"></a>
<h6>27 October 2025 - HttpComponents Client 5.6-alpha1 released</h6>
<p>This is the first ALPHA release in the 5.6 release series. It adds several features such as transport content decompression and content compression for the async transport, support for Unix sockets, experimental support for SCRAM-SHA-256 authentication scheme, and Micrometer/OTel observations &amp; metrics.</p></section><section><a id="a13_October_2025_-_HttpComponents_Core_5.4-alpha1_released"></a>
<h6>13 October 2025 - HttpComponents Core 5.4-alpha1 released</h6>
<p>This is the first ALPHA release in the 5.4 release series that improves HTTP/2 protocol support by ensuring conformance to the latest HTTP specification (RFC 9113) and adds support for Unix domain sockets.</p></section><section><a id="a22_September_2025_-_HttpComponents_Core_5.3.6_GA_released"></a>
<h6>22 September 2025 - HttpComponents Core 5.3.6 GA released</h6>
<p>This maintenance release fixes a regression introduced by the previous release that can cause a temporary I/O spin during HTTP/2 connection shutdown in case the opposite endpoint fails to send a GOAWAY frame, and also fixes several bugs related to abnormal termination of HTTP/2 connections found since the last release.</p></section><section><a id="a2_September_2025_-_HttpComponents_Core_5.3.5_GA_released"></a>
<h6>2 September 2025 - HttpComponents Core 5.3.5 GA released</h6>
<p>This maintenance release fixes several corner cases in the H2 protocol handler that could have been potentially exploited to make H2 endpoints allocate extra resources and lead to Denial-of-Service conditions. This release also improves handling of H2 stream abnormal termination.</p></section><section><a id="a26_May_2025_-_HttpComponents_Client_5.5_GA_released"></a>
<h6>26 May 2025 - HttpComponents Client 5.5 GA released</h6>
<p>This is the first GA release in the 5.5 release series. It adds several experimental features and improvements such as request multiplexing over a shared HTTP/2 connection and the Classic API facade acting as a compatibility bridge between classic I/O client services and the asynchronous message transport used internally.</p>
<p>Notable changes and features included in the 5.5 series:</p>
<ul>

<li>
<p>Improved conformance to RFC 7616 (HTTP Digest Access Authentication).</p></li>
<li>
<p>The connection pool implementation acts as a caching facade in front of a standard managed connection pool and shares already leased connections to multiplex message exchanges over active HTTP/2 connections. Experimental.</p></li>
<li>
<p>Extended Auth API and improved authentication protocol logic to support mutual authentication.</p></li>
<li>
<p>The Classic API facade acting as a compatibility bridge between the classic I/O client services (based on the standard InputStream / OutputStream model) and the asynchronous message transport used internally. Experimental.</p></li>
<li>
<p>HTTP/2 support for the Fluent Facade (via Classic API facade). Experimental.</p></li>
</ul></section><section><a id="a28_April_2025_-_HttpComponents_Client_5.4.4_GA_released"></a>
<h6>28 April 2025 - HttpComponents Client 5.4.4 GA released</h6>
<p>This maintenance release corrects several regressions reported since the last release, including a defect causing some private domains in SSL certificates to get rejected as a mismatch.</p></section><section><a id="a27_March_2025_-_HttpComponents_Client_5.4.3_GA_released"></a>
<h6>27 March 2025 - HttpComponents Client 5.4.3 GA released</h6>
<p>This maintenance release upgrades HttpCore to version 5.3.4 and fixes a regression preventing the PublicSuffixMatcherLoader from finding the resource containing the Public Suffix List and causing the Public Suffix List to be empty by default.</p></section><section><a id="a20_March_2025_-_HttpComponents_Core_5.3.4_GA_released"></a>
<h6>20 March 2025 - HttpComponents Core 5.3.4 GA released</h6>
<p>This maintenance release fixes several corner-case defects in the asynchronous HTTP/1.1 protocol handler as well as several other minor defects.</p></section><section><a id="a17_Feb_2025_-_HttpComponents_Client_5.5-alpha1_released"></a>
<h6>17 Feb 2025 - HttpComponents Client 5.5-alpha1 released</h6>
<p>This is the first ALPHA release in the 5.5 release series. It adds several experimental features and improvements such as request multiplexing over a shared HTTP/2 connection and the Classic API facade acting as a compatibility bridge between classic I/O client services and the asynchronous message transport used internally.</p></section><section><a id="a3_Feb_2025_-_HttpComponents_Client_5.4.2_GA_released"></a>

<h6>13 January 2025 - HttpComponents Core 5.3.2 GA released</h6>
<p>This is a maintenance release that corrects several major defects in the HTTP/2 protocol code reported since the 5.3.1 release.</p></section><section><a id="a28_October_2024_-_HttpComponents_Client_5.4.1_GA_released"></a>
<h6>28 October 2024 - HttpComponents Client 5.4.1 GA released</h6>
<p>This is a maintenance release that upgrades HttpCore to version 5.3.1 and fixes several defects found since release 5.4.</p></section><section><a id="a23_October_2024_-_HttpComponents_Core_5.3.1_GA_released"></a>
<h6>23 October 2024 - HttpComponents Core 5.3.1 GA released</h6>
<p>This is a maintenance release that corrects several defects found since 5.3 release including an HTTP/2 protocol handler failure to notify the opposite endpoint when using non-default dynamic table sizes.</p></section><section><a id="a23_September_2024_-_HttpComponents_Client_5.4_GA_released"></a>
<h6>23 September 2024 - HttpComponents Client 5.4 GA released</h6>
<p>This is the first GA release in the 5.4 release series. This release finalizes the 5.4 APIs, upgrades HttpCore to version 5.3 and improves the Public Suffix matching algorithm implementation.</p>
<p>Notable changes and features included in the 5.4 series:</p>
<ul>

<li>
<p>Improved conformance to RFC 9110 (HTTP Semantics), RFC 7616 (HTTP Digest Access Authentication), RFC 2617 (&#x2019;Basic&#x2019; HTTP Authentication Scheme).</p></li>
<li>
<p>UTF-8 encoding is used by default for text where appropriate.</p></li>
<li>
<p>Compatibility with Java Virtual Threads and Java 21 Runtime.</p></li>
<li>
<p>Redesign and rewrite of the HTTP caching protocol layer for better efficiency and improved conformance to RFC 9111 (HTTP Caching).</p></li>
<li>
<p>Cache control and context APIs.</p></li>
<li>
<p>ETag APIs.</p></li>
<li>
<p>TLS SNI and endpoint identification improvements.</p></li>
<li>
<p>Support for RFC 2817 (Upgrading to TLS Within HTTP/1.1).</p></li>
<li>
<p>Auth cache no longer makes use of Java serialization.</p></li>
<li>
<p>Deprecation of ConnectionSocketFactory and LayeredConnectionSocketFactory.</p></li>
<li>
<p>HttpContext optimization and performance improvement.</p></li>
<li>
<p>Async cache is no longer considered experimental.</p></li>
</ul></section><section><a id="a12_September_2024_-_HttpComponents_Core_5.3_GA_released"></a>
<h6>12 September 2024 - HttpComponents Core 5.3 GA released</h6>
<p>This is the first GA release in the 5.3 release series. This release finalizes the 5.3 APIs and improves integration test configuration APIs along with many test code improvements</p>
<p>Notable changes and features included in the 5.3 series:</p>
<ul>

<li>
<p>Improved conformance to RFC 9110 and RFC 9112.</p></li>
<li>
<p>UTF-8 encoding to be used by default for text where appropriate.</p></li>
<li>
<p>Compatibility with Java Virtual Threads and Java 21 Runtime.</p></li>
<li>
<p>Message parsing API improvements and performance optimization</p></li>
<li>
<p>TLS client endpoints to make use of JSSE Endpoint Identification by default.</p></li>
<li>
<p>Redesign of server-side request routing API.</p></li>
<li>
<p>Redesign of TLS session handling by classic (blocking) connections.</p></li>
</ul></section><section><a id="a3_July_2024_-_HttpComponents_Core_5.2.5_GA_released"></a>
<h6>3 July 2024 - HttpComponents Core 5.2.5 GA released</h6>
<p>This is a maintenance release that corrects several minor defects discovered since release 5.2.4.</p></section><section><a id="a27_June_2024_-_HttpComponents_Client_5.4-beta1_released"></a>
<h6>27 June 2024 - HttpComponents Client 5.4-beta1 released</h6>
<p>This is the first BETA release in the 5.4 release series. It upgrades HttpCore to version 5.3-beta1 and adds a few minor improvements and fixes.</p></section><section><a id="a26_June_2024_-_HttpComponents_Core_5.3-beta1_released"></a>
<h6>26 June 2024 - HttpComponents Core 5.3-beta1 released</h6>
<p>This is the first BETA release in the 5.3 release series. It features a re-designed classic (blocking) TLS session management and server-side request routing APIs. It is likely to be the last BETA release in the 5.3 release series.</p></section><section><a id="a11_March_2024_-_HttpComponents_Client_5.4-alpha2_released"></a>
<h6>11 March 2024 - HttpComponents Client 5.4-alpha2 released</h6>

<p>The third ALPHA release brings another round of API refinements and improvements in functionality. As of this release HttpClient requires Java 5 compatible runtime environment and takes full advantage of generics and new concurrency primitives.</p>

<h6>20 July 2007 - HttpComponents HttpClient 4.0-alpha1 released</h6>
<p>This release represents a complete, ground-up redesign and almost a complete rewrite of the old HttpClient 3.x codeline. This release finally addresses several design flaws that existed since the 1.0 release and could not be fixed without a major code overhaul and breaking API compatibility.</p>
<p>Notable changes and enhancements:</p>
<ul>

<li>Redesign of the HttpClient internals addressing all known major architectural shortcomings of the 3.x codeline</li>
<li>Cleaner, more flexible and expressive API</li>
<li>Better performance and smaller memory footprint due to a more efficient HTTP transport based on HttpCore. HttpClient 4.0 is expected to be 10% to 25% faster than HttpClient 3.x codeline</li>
<li>More modular structure</li>
<li>Pluggable redirect and authentication handlers</li>
<li>Support for protocol incerceptors</li>
<li>Improved connection management</li>
<li>Improved support for sending requests via a proxy or a chain of proxies</li>
<li>Improved handling redirects of entity enclosing requests</li>
<li>More flexible SSL context customization</li>
<li>Reduced intermediate garbage in the process of generating HTTP requests and parsing HTTP responses</li>
</ul></section><section><a id="a4_July_2007_-_HttpComponents_HttpCore_4.0-alpha5_released"></a>
