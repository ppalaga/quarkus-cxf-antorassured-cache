<p id="mwBA">The <b id="mwBQ">Jakarta XML Web Services</b> (<b id="mwBg">JAX-WS</b>; formerly <b id="mwBw">Java API for XML Web Services</b>) is a <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Jakarta_EE" title="Jakarta EE" id="mwCA">Jakarta EE</a> <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Application_programming_interface" title="Application programming interface" class="mw-redirect" id="mwCQ">API</a> for creating <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Web_service" title="Web service" id="mwCg">web services</a>, particularly <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/SOAP" title="SOAP" id="mwCw">SOAP</a> services. JAX-WS is one of the <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Java_XML" title="Java XML" id="mwDA">Java XML</a> programming APIs.</p>

<meta property="mw:PageProp/toc" id="mwDQ" data-mw='{"autoGenerated":true}'/></section><section data-mw-section-id="1" id="mwDg" aria-labelledby="Overview"><div class="mw-heading mw-heading2"><h2 id="Overview">Overview</h2><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=Jakarta_XML_Web_Services&amp;action=edit&amp;section=1" title="Edit section: Overview"><span>edit</span></a><span class="mw-editsection-bracket">]</span></span></div>
<p id="mwDw">The JAX-WS 2.2 specification <a rel="mw:ExtLink nofollow" href="http://jcp.org/en/jsr/detail?id=224" class="external text" id="mwEA">JSR 224</a> defines a standard Java- to-WSDL mapping which determines how <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Web_Services_Description_Language" title="Web Services Description Language" id="mwEQ">WSDL</a> operations are bound to Java methods when a SOAP message invokes a WSDL operation. This Java-to-WSDL mapping determines which Java method gets invoked and how that SOAP message is mapped to the method's parameters.</p>

<p id="mwEg">This mapping also determines how the method's return value gets mapped to the SOAP response.</p>

<p id="mwEw">JAX-WS uses <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Java_annotation" title="Java annotation" id="mwFA">annotations</a>, introduced in <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Java_Platform,_Standard_Edition" title="Java Platform, Standard Edition" id="mwFQ">Java SE 5</a>, to simplify the development and deployment of web service clients and endpoints. It is part of the <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Java_Web_Services_Development_Pack" title="Java Web Services Development Pack" id="mwFg">Java Web Services Development Pack</a>. JAX-WS can be used in <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Java_Platform,_Standard_Edition" title="Java Platform, Standard Edition" id="mwFw">Java SE</a> starting with version 6.<sup about="#mwt8" class="mw-ref reference" id="cite_ref-1" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{},"body":{"id":"mw-reference-text-cite_note-1"}}'><a href="#cite_note-1" id="mwGA"><span class="mw-reflink-text" id="mwGQ"><span class="cite-bracket" id="mwGg">[</span>1<span class="cite-bracket" id="mwGw">]</span></span></a></sup> As of Java SE 11, JAX-WS was removed. For details, see <a rel="mw:ExtLink nofollow" href="http://openjdk.java.net/jeps/320" class="external text" id="mwHA">JEP 320</a>.</p>

<p id="mwHQ">JAX-WS 2.0 replaced the <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Java_API_for_XML-based_RPC" title="Java API for XML-based RPC" class="mw-redirect" id="mwHg">JAX-RPC</a> API in <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Java_Platform,_Enterprise_Edition" title="Java Platform, Enterprise Edition" class="mw-redirect" id="mwHw">Java Platform, Enterprise Edition</a> 5 which leans more towards document style Web Services.</p>

<p id="mwIA">This API provides the core of <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Eclipse_Metro" title="Eclipse Metro" id="mwIQ">Eclipse Metro</a>.</p>

<p id="mwIg">JAX-WS also is one of the foundations of <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Web_Services_Interoperability_Technology" title="Web Services Interoperability Technology" class="mw-redirect" id="mwIw">WSIT</a>.</p>

<section data-mw-section-id="5" id="mwnA" aria-labelledby="Jakarta_Web_Services_Metadata"><div class="mw-heading mw-heading3"><h3 id="Jakarta_Web_Services_Metadata">Jakarta Web Services Metadata</h3><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=Jakarta_XML_Web_Services&amp;action=edit&amp;section=5" title="Edit section: Jakarta Web Services Metadata"><span>edit</span></a><span class="mw-editsection-bracket">]</span></span></div>

<p id="mwnQ"><b id="mwng">Jakarta Web Services Metadata</b> (<b id="mwnw">JWS</b>; formerly Web Services Metadata for Java platform and Java Web Services), as a part of Jakarta XML Web Services (JAX-WS), is a Java programming language specification (JSR-181) primarily used to standardize the development of <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Web_service" title="Web service" id="mwoA">web service</a> interfaces for the <a rel="mw:WikiLink" href="https://en.wikipedia.org/wiki/Jakarta_EE" title="Jakarta EE" id="mwoQ">Jakarta EE</a> platform. Version is 2.1 was released on December 15, 2009.<sup about="#mwt11" class="mw-ref reference" id="cite_ref-2" rel="dc:references" typeof="mw:Extension/ref" data-mw='{"name":"ref","attrs":{},"body":{"id":"mw-reference-text-cite_note-2"}}'><a href="#cite_note-2" id="mwog"><span class="mw-reflink-text" id="mwow"><span class="cite-bracket" id="mwpA">[</span>2<span class="cite-bracket" id="mwpQ">]</span></span></a></sup></p>
